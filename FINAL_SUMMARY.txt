🚀 QUICK START (5 MINUTES)

1. Clone Repository:
   git clone https://github.com/manish00717s/Fake-Spam-Classifier.git

2. Setup Environment:
   python -m venv venv
   source venv/bin/activate
   pip install -r requirements.txt

3. Download Dataset:
   • Get spam.csv from Kaggle
   • Create data/ folder
   • Place spam.csv inside

4. Run Notebooks:
   jupyter notebook
   → Week_2_EDA_DataPrep/data_preparation.ipynb
   → Week_3_Modeling/model_training.ipynb

5. Deploy Web App:
   streamlit run Week_6_Deployment/app/streamlit_app.py
