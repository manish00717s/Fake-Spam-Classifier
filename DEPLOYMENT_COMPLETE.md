## 🚀 Quick Start (5 Minutes)

### 1. Clone the Repository
```bash
git clone https://github.com/manish00717s/Fake-Spam-Classifier.git
cd Fake-Spam-Classifier
```

### 2. Setup Environment
```bash
python -m venv venv
source venv/bin/activate  # On Windows: venv\Scripts\activate
pip install -r requirements.txt
```

### 3. Download Dataset
- Go to: https://www.kaggle.com/datasets/uciml/sms-spam-collection-dataset
- Download `spam.csv`
- Create `data/` folder (if needed)
- Place `spam.csv` in `data/` folder

### 4. Run Notebooks
```bash
jupyter notebook
# Open Week_2_EDA_DataPrep/data_preparation.ipynb
# Execute all cells
# Then run Week_3_Modeling/model_training.ipynb
```

### 5. Deploy Web App
```bash
streamlit run Week_6_Deployment/app/streamlit_app.py
```
